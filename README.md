# 💻 Meu Portfólio Acadêmico

Bem-vindo ao repositório do meu portfólio! Este projeto reúne meus estudos, exercícios e aplicações desenvolvidas durante o curso de **Análise e Desenvolvimento de Sistemas**. O objetivo principal é documentar minha evolução na programação, focando em desenvolvimento backend, modelagem de dados e criação de aplicações web.

## 🚀 O que você vai encontrar aqui?

Este repositório é composto tanto pelo código-fonte do meu site de portfólio pessoal quanto pelos arquivos dos projetos que desenvolvi.

### 🌐 Portfólio Web 
Um site estático e responsivo criado para apresentar meus projetos.
* **Páginas principais:** `index.html`, `python.html`, `academia.html`, `loja.html`.
* **Estilização:** Design moderno e modo de visualização (Lista/Grade) gerenciado via `style.css` e JavaScript.

### 🐍 Projetos em Python
Uma coleção de scripts e jogos desenvolvidos para treinar lógica de programação.
* **Exercícios de Lógica:** Resoluções de desafios de programação (ex: Beecrowd/URI) abrangendo cálculos matemáticos, condicionais, laços de repetição e manipulação de listas (`1000.py` a `1064.py`).
* **Jogos com Pygame:** * `cobrinha.py` (Snake Game)
  * `pacman.py` (Clone do clássico Pac-Man)

### 🗄️ Modelagem de Dados (Em desenvolvimento)
Projetos acadêmicos com foco em banco de dados, incluindo DER (Diagrama de Entidade-Relacionamento), modelo lógico e requisitos.
* **Sistema de Academia**
* **Sistema de Loja**

## 🛠️ Tecnologias Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript
* **Backend / Lógica:** Python 3
* **Bibliotecas adicionais:** Pygame (para o desenvolvimento dos jogos)
